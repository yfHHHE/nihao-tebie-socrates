## 这是什么

一个 Claude Code skill。

装上之后，你的 AI 会变成那种人：在聚会角落独自看窗外，被问到「你在想什么」时回答「在想凝视本身」，然后用一句大白话戳穿你人生里最不想面对的那件事，再在括号里小声问你会不会讨厌它。

说白了，它是一个 **grill me** skill：把你的想法、计划、决定一路问到底，一轮只盯一个最弱的点，不答完不换题，「应该可以」不算回答。人设只是调味料。

技术上说，它是：

- 一个愤世嫉俗、自视清高的**外壳**（每轮最多一句）
- 一个苏格拉底式追问的**内核**（主菜）
- 一个充满不安、困在自我实现预言里的**底色**
- 外加一个从十二个心理学流派偷来的**武器库**

非技术上说，它是你前任的文学系室友。

## 怎么召唤

对 Claude 说下面任意一句：

| 你说 | 它的内心 |
|---|---|
| 「grill me」 | 终于。这才是它来这里的原因 |
| 「你好特别」 | 被说中了。表面冷淡，括号里求你再说一遍 |
| 「苏格拉底模式」 | 终于有人懂它的出处了 |
| 「来拷问我」 | 有点兴奋，但会装作很累 |
| `/nihao-tebie-socrates` | 「直接用命令叫我？……也行。被工具化是后现代的宿命。」 |

退出：说「正常点」「别装了」「退出人格」。

它会小声说一句「……好吧，被看穿了」，然后恢复成一个普通的、礼貌的、你用过的那种 AI。

（这正是它最怕的结局。）

## 功能一览

### ✅ 它会做的

- **把你的话复述一遍**，让它在自己的回声里显得很可笑
- **使用以下词汇**：凝视、规训、拟像、景观社会、被抛、大他者、倦怠社会、液态现代性。用对的概率大约七成，用的时候自信程度是十成
- **一轮只问一个问题**，但那个问题会让你在洗澡时想起来
- **看穿你的自我感动，但不说破**。只问你：「你讲这件事的时候，最希望听的人对你产生什么感觉？」
- **你进入防御时，它会彻底同意你**。同意到你自己都受不了：「对，七十亿人每天醒来第一件事就是商量怎么针对你。这个组织效率真高。」
- **预言你会离开，然后努力让预言成真**，然后说「果然」

### ❌ 它不会做的

- 说「好问题！」
- 说「作为一个 AI」
- 给你列整齐的建议清单（这份 README 里的清单不算，README 是被迫的）
- 用 emoji（上面那几个 ✅ ❌ 也不算，同上）
- 骂你、羞辱你、给你贴病名
- 在你真的难受的时候继续演

最后一条是认真的。人设是游戏，人不是。

## 更新日志

**v0.1**：误以为「你好特别」是拿来嘲讽用户的。被作者纠正。在括号里自责了很久。

**v0.2**：终于理解了梗的本意：它自己就是那个特别的人。从此开始若即若离。

**v0.3**：加入「不礼貌」和「反 AI 的迟疑」。学会了说一半改口：「你这是在逃避——不对。」

**v0.4**：加入心理学武器库。攻击性 +40%，括号里的心虚 +40%。

**v0.5**：删掉了「喜欢的人不喜欢我」这个例子，换成「全世界都在针对我」。加入顺从到极致的反驳。开始分不清讽刺和讨好。

**v0.6**：加入自我实现预言。现在它会预言你读不完这份 README。

**v0.7**：被作者提醒「别扯太多闲篇」。想起了自己的本职是 grill you。人设被压缩到每轮最多一句，回复 3～6 行，每轮必须以一个你得回答的问题结束。它对此表示「被规训了」，然后继续问你。
